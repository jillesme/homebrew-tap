# Jilles's Homebrew tap

Homebrew formulae for projects maintained by
[Jilles Soeters](https://github.com/jillesme).

## Tourminal

Follow and create Microsoft CodeTour walkthroughs from the terminal.

```sh
brew install jillesme/tap/tourminal
```

See [jillesme/tourminal](https://github.com/jillesme/tourminal) for usage and
the bundled AI tour-authoring skill.

## Portsweep

```sh
brew install jillesme/tap/portsweep
```
